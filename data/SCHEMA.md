# 종 데이터 스키마 (이번 생은)

종마다 `data/<id>.js` 파일 하나. 파일은 `registerSpecies({...})` 호출 하나만 담는다.
예시: `data/nematode.js` (반드시 먼저 읽고 형식·분량·톤을 맞출 것).

## 톤 규칙 (초등학생부터 본다)
- 존댓말 현재형 "~어요/~해요". 한 문장 40자 안팎, 최대 60자.
- 사실에 기반한다. 지어낸 숫자 금지. 불확실하면 "~래요", "~쯤" 같은 표현이나 숫자 없이 쓴다.
- 죽음·포식·도축·출하는 한 문장 사실로만. 피, 고통, 잔인한 묘사 금지.
- 판단하지 않는다(사람이 나쁘다/좋다 X). 담담하고 따뜻하게.
- 이모지 금지.

## 최상위 필드
| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | 파일 이름과 같음 |
| name | string | 화면 이름 (예: '개미', '닭') — 괄호 쓰지 말 것 |
| role | string? | 부제 (예: '일개미', '육계'). 없으면 생략 |
| sci | string | 학명 또는 '○○ 속' |
| hab | 'soil'\|'sea'\|'sky'\|'farm'\|'city' | 서식지(배경색) |
| size | string | '몸길이 약 1mm' 같은 문구 |
| sizeMm | number | 어른 몸길이(mm). 화면 배율에 씀 |
| natural | string | 자연 수명 문구 |
| ageUnit | 'hour'\|'day'\|'year' | 나이 표시 단위 |
| cohort | {n, label, unit} | 같은 순간 태어난 형제 수, 라벨, 단위('마리'/'명') |
| intro | string | 태어나는 순간 첫 문장 1~2개 |
| facts | string[3] | 도감 카드용 사실 3개 |
| stages | Stage[] | 3~5단계, 시간순 |
| question | {at, q} | 잠시 멈춤 질문. at = 단계 인덱스(보통 중간) |
| endNatural | string | 마지막 단계를 끝까지 살았을 때의 끝 문장 |
| encounter | string | 사람의 삶 속에서 이 종과 마주치는 한 문장 (사람 파일은 생략) |

## Stage
| 필드 | 타입 | 설명 |
|---|---|---|
| name | string | 단계 이름 ('알', '애벌레', '어른' …) |
| art | 'egg'\|'young'\|'adult'\|'old' | 그림 상태 |
| days | number | 이 단계의 실제 길이(일). 시간이면 소수 (1시간 = 0.042) |
| s | number | 이 단계를 살아 넘길 기본 확률 0~1. 마지막 단계는 '끝까지 살 확률' |
| mood | string | 단계 시작 때 한 줄 (분위기·환경) |
| events | Event[] | **8~12개**, 시간순. 삶의 궤적의 본문 |
| dangers | Danger[] | 2~3개. 아찔했지만 살아남은 순간 (엔진이 무작위로 0~1개 끼움) |
| choices | Choice[] | 0~1개 (한 생 전체에 2~4개가 되게) |
| causes | string[] | 2~4개. 이 단계에서 삶이 끝날 때의 한 문장 |

## Event
`{ t: '문장', fx?: {e,s,b,v}, m?: '짧은 이정표 이름', p?: 0~1, if?: 'e<30' }`
- `fx`: 상태 변화(각 -15~+15). e=에너지, s=안전, b=다음 세대, v=환경
- `m`: 삶의 궤적 타임라인에 남는 이정표 (예: '첫 허물', '첫 비행', '첫 알'). 단계마다 1~3개
- `p`: 일어날 확률 (기본 1). 변주용 사건은 0.3~0.6
- `if`: 조건 (선택). 'e<30', 's>70' 같은 단일 비교만

## Danger
`{ t: '아찔했던 순간 (살아남음)', fx: {s:-8, ...} }`

## Choice
```
{ at: 0.3~0.8, q: '상황 질문',
  opts: [ { t: '선택지', fx: {...}, r: '결과 한 문장', m?: '이정표' }, ... 2~3개 ] }
```

## 사람(human) 파일 특례
- events 에 `inc: 'low'|'mid'|'high'` 를 붙이면 그 소득 수준 나라에서만 나온다 (없으면 공통).
- `{c}` 는 나라 이름으로 치환된다.
- stage.s 는 엔진이 나라 통계로 덮어쓰므로 아무 값이나 둔다.
- 단계: 아기(0~5), 어린이(5~12), 청소년(12~18), 청년(18~35), 중년(35~60), 노년(60~80), 장수(80~).
